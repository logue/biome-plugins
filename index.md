# @logue/biome-plugins

Custom Biome Lint Rules

> GritQL-based rules that enforce consistent TypeScript conventions across Rstack projects — one package, every template.


[Get Started →](/guide/getting-started) | [Browse Rules](/rules/)

## Features

- 🔍 **GritQL-Powered**: Rules are written in GritQL and executed natively by Biome 2.x. No extra runtime, no post-processors.

- ⚡ **Rstack-First**: Designed for Rslib, Rsbuild, and Rspress-based projects. Works in any codebase that runs Biome.

- 📐 **Single Source of Truth**: TypeScript conventions live here — not duplicated across every project's AGENTS.md. Add a rule once; all templates benefit.

- 🧩 **Framework-Ready**: New rules for Vue, Tauri, or UI libraries slot in as additional .grit files. Extend without bloating per-project configs.
