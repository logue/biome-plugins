# Rules

All rules are written in [GritQL](https://docs.grit.io/) and loaded as Biome plugins.
Each rule file is independent — load only what you need.

## Available Rules

| Rule                                                      | Severity                                        | What it checks                              |
| --------------------------------------------------------- | ----------------------------------------------- | ------------------------------------------- |
| [enforce-attribute-order](/rules/enforce-attribute-order) | <cds-tag type="purple" size="sm">warn</cds-tag> | Adjacent attributes must follow group order |
| [enforce-pure-src](/rules/enforce-pure-src)               | <cds-tag type="red" size="sm">error</cds-tag>   | No Storybook / demo imports inside `src/`   |
| [no-null-type](/rules/no-null-type)                       | <cds-tag type="purple" size="sm">warn</cds-tag> | `\| null` in type annotation positions      |
| [prefer-union-over-enum](/rules/prefer-union-over-enum)   | <cds-tag type="red" size="sm">error</cds-tag>   | `enum` and `const enum` are forbidden       |
| [vue-multi-word-filename](/rules/vue-multi-word-filename) | <cds-tag type="red" size="sm">error</cds-tag>   | Vue filenames must be multi-word PascalCase |

## Rule Locations

Rules live in the `grit/` directory at the root of this package.
Import paths for `biome.jsonc`:

```
node_modules/@logue/biome-plugins/grit/enforce-attribute-order.grit
node_modules/@logue/biome-plugins/grit/enforce-pure-src.grit
node_modules/@logue/biome-plugins/grit/no-null-type.grit
node_modules/@logue/biome-plugins/grit/prefer-union-over-enum.grit
node_modules/@logue/biome-plugins/grit/vue-multi-word-filename.grit
```
